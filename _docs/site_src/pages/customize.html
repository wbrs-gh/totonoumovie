もっと活かす

自分好みに育てる

使うほど自分に合うようにできます。見た目は「マイスタイル」に、言い方や秒数は「設定」に、人名や用語は「表記辞書」に、毎回の頼みごとは「いつもの指示」に、自分の編集ルールは「自作スキル」に覚えさせます。どれも totonoumovie の 🌱 自分好み の画面で育てられ、Claude Code だけで使うときにも同じものが効きます。

気に入った見た目は、マイスタイルに保存しておこう。次から「前回と同じで」で呼び出せるよ。

育て方の流れ

🌱 自分好みの画面

上のバーの 🌱 自分好み を押すと開きます。6つのタブで、自分好みに育てたものを見る・直す・増やすことができます。

タブできること
🎨 マイスタイル一覧・中身の確認・メモの編集・名前の変更・削除。前に作った動画からマイスタイルを作る
🧩 スキル自作スキルを書いて作る・AI に作ってもらう・直す・消す。TotonouMovie の17スキルの一覧
📖 表記辞書全部の動画で使う「誤字の直し」と「字幕で途中で切らない言葉」
⚙ 設定確認者の名前・完成動画のコピー先・美肌の強さ・撮影中の合図・章カードの秒数と効果音。言葉で AI に頼むこともできます
🔊 効果音自分の音に置き換えた効果音の確認と、置き場所のフォルダを開く
🏠 拠点・引き継ぎ全部がまとまっている場所の確認、17スキルを読み込む範囲の切り替え、前の版で作った動画の引き継ぎ

マイスタイル

気に入った見た目を、名前を付けて保存しておく機能です。

  • 保存する：完成のあとに「この見た目をマイスタイルとして保存しますか」と聞かれたら、名前を答えます（例「語りのリール」「講座の YouTube」）。同じ名前があるときは、上書きするか別の名前にするかを聞かれます
  • 呼び出す：マイスタイルがあると、次の動画の最初に「前回と同じ（〇〇）で／別のマイスタイル／新しく決める」と1問だけ聞かれます。最初から「マイスタイル『語りのリール』で」と追加の指示に書いてもかまいません
保存される保存されない（動画ごとに聞かれる）
雰囲気・テンポ・字幕のスタイル・効果音・画像のレイアウト・BGM・章カード・美肌の強さ・人名や用語の表記動画の長さ、最後の案内文（CTA）、無音を切るかどうか
  • ショート用・ロング用・アフレコ用は別々に作ります（種類の違うマイスタイルは使えません）
  • BGM は曲の名前だけを覚えています。次に使うときは、同じ曲を置くように頼まれます
  • 一覧・確認・削除は 🌱 自分好み の画面でできます（AI に「マイスタイルの一覧を見せて」と頼んでもかまいません）

画面で選ぶ・育てる

  • 選ぶ：「🎬 AIで作る」の「マイスタイル」で選びます。「AI に任せる」なら、今までどおり最初に「前回と同じで」と聞かれます。「使わない」を選ぶと、新しく決めます
  • メモ：そのマイスタイルで毎回守ってほしいこと（例「人名は必ず確認してから字幕に」）を書いておきます。いつもの指示は「＋」のボタンでメモに入れられます。メモは Claude Code だけで使うときにも守られます
  • 動画から作る：前に作った動画（前の版や Claude Code だけで作ったものも）を選んで名前を付けると、その動画の見た目を取り出して保存します

スキルを選ぶ・自分のスキルを作る

スキルは、AI が従う手順書です。TotonouMovie の17スキル（機能の一覧）に加えて、自分の編集ルールを「自作スキル」として残せます。

  • 作る：🧩 スキル のタブで「＋ 自分で書いて作る」（名前・いつ使うか・中身）か、やりたいことを書いて「AI に作ってもらう」
  • 使う：「🎬 AIで作る」と「AI」タブの「AI に頼む」で、「使うスキルを選ぶ」を開いてチェックします。17スキルは選ばなくても AI が必要なものを使います。「この作業は字幕のスキルで」のように指定したいときに選びます
  • 置き場所：自作スキルは totonoumovie のフォルダの中（.claude/skills）にだけ作ります。動画編集以外の作業では読み込まれません

いつもの指示とプロンプト（totonoumovie）

上の ✍ プロンプト で、AI に渡す文章を自分好みにできます。保存先は totonoumovie のフォルダの中（my/app/prompts.json）です。

欄使いどころ
いつもの指示名前を付けて保存し、「AIで作る」「AI に頼む」のときにチェックで足せます。例「テンポよく：迷ったらテンポを詰める方向で提案して」「固有名詞：人名は必ず確認してから字幕にして」
毎回足す指示すべての依頼の最後に足されます
AIで作る／直してもらう／自由に頼む種類ごとに渡す文章そのもの。{video} などは実行時に置き換わります
AI への前提（上級者向け）AI が画面で確認を出すための決まり（tm-ask）が書いてあります。消すと確認が画面に出なくなります

書き換えたものは「既定に戻す」でいつでも元に戻せます。

Claude Code だけで使うときにも効かせたい

いつもの指示は totonoumovie の画面の中のものです。Claude Code だけで編集するときにも同じ指示を守らせたいときは、マイスタイルのメモに入れておきます。

設定を変える

セットアップで決めたことや既定の値は、🌱 自分好み の「⚙ 設定」タブで変えられます。AI に言葉で頼んでも変えてくれます（設定タブの「言葉で頼む」でも、Claude Code でも）。

変えたいこと頼み方の例
完成動画のコピー先・名前「完成動画を〇〇のフォルダにもコピーしたい」（動画のプロジェクトは、いつも totonoumovie のフォルダの projects に作られます）
美肌の強さ（既定は縦60・横40。横は出演者が女性なら60）「縦動画の美肌を40にしたい」
撮影中の合図の言い方「合図の言い方を『カメラさん、ここに章』に変えたい」
章カードの秒数と効果音「章カードを3秒にしたい」「章カードの効果音をなしにしたい」
いまの設定を見る「TotonouMovie の設定を見せて」

設定は totonoumovie のフォルダの中（my/config）に保存されます。新しい版に入れ替えても消えません。

表記辞書を育てる

人名・社名・商品名・専門用語の正しい表記を伝えると、その動画の辞書に入り、文字起こし・誤字の修正・字幕・検査で使われます。2本以上の動画で同じ直しが出ると、全部の動画で使う共通の辞書に足すかを提案されます。共通の辞書は 🌱 自分好み の「📖 表記辞書」タブで、見る・足す・消すができます。

例
表記は「山田太郎」（「山田たろう」「山田太朗」と出ることがある）

効果音を自分の音にする

同梱の効果音の代わりに、自分で用意した音（効果音ラボなどで手に入れた音）を使えます。🌱 自分好み の「🔊 効果音」タブの「自分の効果音のフォルダを開く」で開くフォルダ（my/config/se-library）に、同梱の音と同じファイル名で置くと、そちらが優先されます。タブには、どの音を自分の音に置き換えたかが出ます。置き場所とファイル名は、AI に「自分の効果音を使いたい」と伝えると案内します。量は動画ごとに「効果音を少なめに」「効果音なしで」と頼めます。totonoumovie の編集画面でも、1つずつ足したり消したりできます。

全部ひとつのフォルダに（Claude Code だけで使うときも）

動画も自分好みも、totonoumovie のフォルダ（入れた場所。ふつうはホームの totonoumovie）の中にまとまっています。フォルダごと別の場所へ移しても、そのまま使えます。

フォルダ中身
projects動画のプロジェクト（作った動画・書き出した完成動画）
myマイスタイル・設定・表記辞書・自分の効果音・いつもの指示
.claude/skills自作スキル
  • Claude Code だけで編集する：このフォルダで claude を起動して「この動画を編集して」と頼みます。画面と同じマイスタイル・設定・自作スキルが使え、Claude Code で保存したマイスタイルも画面に出ます
  • 17スキルを動画の作業だけで使う：「🏠 拠点・引き継ぎ」タブの「この拠点でだけ使う」を押すと、動画と関係ない Claude Code の作業では17スキルが読み込まれなくなります（読み込みの分だけ軽くなります）。totonoumovie から AI を動かすときは、どちらでも使えます
  • 前の版（Claude Code だけ）を使っていた方：最初の起動で、設定・マイスタイル・表記辞書・自分の効果音を自動で引き継ぎます（元の場所にも残ります）。前の作業フォルダ（ムービーの中の totonou など）の動画は、「🏠 拠点・引き継ぎ」タブで選んで移せます。移さなくても、動画からマイスタイルを作るで見た目だけ取り出せます
クラウド同期のフォルダに置くとき

Dropbox などの中に置くと、書き出し中に同期とぶつかって止まることがあります。止まるときは、書き出しの間だけ同期を一時停止してください。

直し方のコツ

字幕の誤字やタイミング、効果音の位置などは編集画面で自分で直すのが確実です。AI に頼むときは、どの場面か・その時の発言・直したいこと・残したいことの4点で伝えます。

直したいこと頼み方の例
字幕の誤字「2分10秒あたりの『確立』を『確率』に」
字幕のタイミング「45秒あたりの字幕が声より早い。声に合わせて」
話者の取り違え（対談）「3分あたりから話者が逆になっている」
カットを戻す「1分05秒あたりで切った言い直しを戻して」（画面のカット承認でも戻せます）
演出の量「効果音を半分くらいに」「強調を減らして」
画像「2枚目の画像を外して」「この写真を最初の章に」
BGM の音量「BGM を標準にして」

切りすぎを戻す

カットの承認のあと、「切りすぎた」と思ったら、その候補のチェックを外して承認し直すと、消えた字幕と一緒に戻ります。ロングは完成のあとでも戻して書き出し直せます。ショートは、冒頭のつかみ（フック）を入れる前までです（フックを「なし」にしたときは、あとからでも戻せます）。

頼み方のコツ

  • 1回に1つ：直したいことが多いときは、大事なものから1つずつ
  • 理由を聞く：「なぜこの候補を切ろうとしたの？」と聞くと、根拠を教えてくれます
  • 案を出してもらう：「最後の案内文の案を3つ出して」のように、選べる形で頼みます
  • 自分のルールを残す：毎回伝えたいことは「いつもの指示」か、マイスタイルのメモに。手順ごと残したいときは自作スキルにします
