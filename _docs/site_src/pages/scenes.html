使える場面と頼み方メーカー

場面ごとのおすすめと、選ぶだけで「AI への頼み方」の文章ができる道具です。できた文章は、totonoumovie の「今回だけの追加の指示」に貼るか、Claude Code にそのまま送ります。

2. 内容は？（おすすめの雰囲気が自動で選ばれます）
3. 字幕の雰囲気
4. テンポ
3. 話している人は？
5. 入れたいもの（あれば）

画像のフォルダ（あとで書き換えてもOK）

正しい表記（読点で区切る）
マイスタイルの名前（空なら「前回と同じ」）

縦動画（リール・ショート）の場面

  
場面おすすめ

    
📚 毎日の発信（1人語りのノウハウ・解説）落ち着き＋流行りの字幕、テンポは詰める、最後に案内文（CTA）

    
💗 想いを届ける（体験談・ストーリー）表情をつけた語り。強調の一言だけ書体や配置が変わり、声の表情が字幕に乗ります

    
🕊 言葉を届ける（名言・語り）縦書き白テロップ。静かな語りに合います

    
🎉 楽しく見せる（料理・エンタメ・ネタ）派手め。色と動きの多い字幕で、仕上げで1.1倍速になります

    
📣 集客（セミナー・講座の告知）冒頭のつかみ（フック）＋最後の案内文「お申し込みはプロフィールから」。告知画像のスクショを画像として入れます

    
🙈 顔を出さない（お店・旅・日常の紹介）アフレコ動画。声の録音と、風景や手元の動画・写真から作ります

  






  
横動画（YouTube）の場面

  
場面おすすめ

    
🎓 講座・セミナー撮影中に「編集さん、ここに章」と言って区切ると、章カードとチャプターが自動で入ります。スライドのスクショは「収める」で差し込めます

    
🗣 対談・インタビュー①で「対談」と答えると、話者ごとに字幕を分けます

    
🛍 商品・サービスの紹介商品の写真は「全画面」、サイトのスクショは「収める」、縦長の SNS 投稿は人物の横に「分割」で出せます

    
🧭 やり方・手順の解説「編集さん、ここに一覧」のあとに項目を話すと、話した順に1行ずつ増える一覧の字幕になります

  






  
素材を整える

  

    
↕ 縦にする
横で撮った動画を縦に
顔を追いかけて縦（9:16）に切り出してからショートにできます。追うのはいちばん大きい顔だけです。

    
✨ 美肌
肌と色味を整える
顔の美肌補正（強さは変えられます）と、色味の調整ができます。編集の最初に行います。

    
🔁 両方
横の動画からショートも
同じ元の動画から、縦のショートを別に作れます。横の完成動画をそのまま縦にした版は、字幕の端が見切れることがあります。
