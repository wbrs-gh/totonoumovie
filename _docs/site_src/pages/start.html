はじめに

準備と全体の流れ

入れ始める前に、必要なものとパソコンの条件を確かめます。ここを読めば、どこで何をするのかが全部見通せます。

入れるのは最初の1回だけだよ。ダウンロードの待ち時間が長いから、飲み物を用意してから始めてね。

全体の流れ（導入は1回だけ）

必要なもの

必須

Claude の有料プラン

Pro・Max・Team・Enterprise のどれか。無料プランでは Claude Code を使えません。AI の作業は、このアカウントで動きます（API キーは不要）。

必須

TotonouMovie の zip

配布元から案内された配布フォルダから TotonouMovie-v2.2.0.zip を落とします。会員ご本人だけが使えます。

無料の道具

uv・ffmpeg・Node.js ほか

動画の処理と書き出しに使います。導入の途中で、コマンドを貼り付けて入れます。

配布物は、ご本人だけで使います

TotonouMovie の zip や配布フォルダのリンクは、ほかの人に渡したり共有したりしないでください（画面のアプリ totonoumovie は公開しているので、だれでも入れられます。使うには TotonouMovie が要ります）。

回線が遅いとき

最初の書き出しで「Timed out」と出ることがあります。もう一度実行すれば続きから進みます。くわしくは 困ったとき。

このマニュアルの読み方

  • 黒い枠はターミナル（Windows は PowerShell）に貼るコマンド、オレンジの枠は Claude Code に送る言葉、水色の枠は totonoumovie の画面に書く言葉です。右下の「コピー」でそのままコピーできます
  • Mac と Windows で違う所は、画面右上の切り替えで表示が変わります（選んだものは覚えておきます）
  • 点線の下線が付いた言葉（パス など）は、触ると意味が出ます
  • 画面右上の「🔍 さがす」（⌘K）で、マニュアル全体を検索できます
  • 「あなたの名前」「talk.mp4」のような部分は、ご自分の名前やファイル名に置き換えてください
