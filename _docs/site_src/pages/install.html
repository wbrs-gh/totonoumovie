Homebrew があるか確かめる1分

ターミナル
brew -v

Homebrew 4.x のようにバージョンが出る → 次の手順へ

「command not found」と出たら、次の1行で Homebrew（Mac 用の道具の入れ物）を入れます。

ターミナル
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • Mac のパスワードを聞かれたら、入力して Enter（入力中は文字が見えませんが、入っています）
  • 「Press RETURN」と出たら Enter。開発用の部品（Xcode のコマンドラインツール）の取得が始まったら、数分〜十数分待ちます
最後に「==> Next steps:」が出たら

その下に出ている行（echo や eval で始まる行）を、上から順に貼り付けて実行します。Apple シリコンの Mac（M1〜M5）なら、次の3行と同じです。入れたのに「command not found」と出るときは、ここがまだです。

ターミナル（Apple シリコンの Mac）
echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

ターミナルを閉じて開き直し、もう一度 brew -v で確かめます。

おすすめ：17スキルを動画の作業だけで使う

上の 🌱 自分好み →「🏠 拠点・引き継ぎ」→「この拠点でだけ使う」を押すと、動画と関係ない Claude Code の作業では TotonouMovie のスキルが読み込まれなくなります。Claude Code だけで動画を編集するときは、totonoumovie のフォルダで claude を起動します（くわしく）。

前の版（Claude Code だけ）を使っていた方
