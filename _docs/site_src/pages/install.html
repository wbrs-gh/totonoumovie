入れかた

上から順に、黒い枠のコマンドを「コピー」→貼り付け→Enter で進めます。終わった手順は「できた」を押すと、次の手順まで自動で進みます。右上で Mac／Windows を選んでから始めてください。

TotonouMovie をすでに使っている方

Claude Code で「TotonouMovie のセットアップをして」が PASS まで済んでいれば、後半の「B. totonoumovie を入れる」だけで大丈夫です。

ATotonouMovie を入れる

動画を編集する中身（TotonouMovie）を、Claude Code に入れます。配布元の導入ガイドと同じ手順です。

ターミナルを開く10秒

⌘＋スペース を押して「ターミナル」と入力し、Enter で開きます。文字を入力する窓が開きます。このページの黒い枠のコマンドは、ここに貼り付けて Enter を押します。

Homebrew があるか確かめる1分

ターミナル
brew -v

Homebrew 4.x のようにバージョンが出る → 次の手順へ

「command not found」と出たら、次の1行で Homebrew（Mac 用の道具の入れ物）を入れます。

ターミナル
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • Mac のパスワードを聞かれたら、入力して Enter（入力中は文字が見えませんが、入っています）
  • 「Press RETURN」と出たら Enter。開発用の部品（Xcode のコマンドラインツール）の取得が始まったら、数分〜十数分待ちます
最後に「Next steps」が出たら

表示された2行のコマンドを順に貼り付けて実行し、ターミナルを開き直してから、もう一度 brew -v で確かめます。入れたのに「command not found」と出るときは、この2行がまだ実行されていません。

動画編集の道具をまとめて入れる3〜10分

ターミナル
brew install uv ffmpeg node gh python

最後にプロンプト（% の記号）が戻る

uv・ffmpeg・Node.js は TotonouMovie に、gh・Python は totonoumovie に使います。

Claude Code のターミナル版を入れる3分

ターミナル
claude --version

数字と (Claude Code) が出る → 入っているので次の手順へ

「command not found」と出たら入れます。ダウンロードの間は何も表示されません。

ターミナル
curl -fsSL https://claude.ai/install.sh | bash

終わったらターミナルの窓を閉じて新しく開き、もう一度 claude --version で確かめます。

なぜターミナル版？

プラグインを入れるコマンドは、デスクトップアプリの Code タブでは使えないためです。入れたあとは、デスクトップアプリとターミナル版のどちらからでも TotonouMovie を使えます。

TotonouMovie のフォルダを置く1分

  1. 落とした TotonouMovie-v2.2.0.zip をダブルクリック → 「TotonouMovie」フォルダができます
  2. Finder で ⌘＋Shift＋H を押すとホームフォルダ（家のマーク）が開きます。そこへ「TotonouMovie」フォルダを移します
  3. 中に README.md と plugins フォルダが見えれば正しい場所です
このフォルダは、消したり動かしたりしない

Claude Code はここから TotonouMovie を読み込みます。動かすと「failed to load」と出て動かなくなります。

PowerShell を開く10秒

スタートメニューで「PowerShell」と入力して開きます。PS C:\Users\あなたの名前> と出た窓に、このページの黒い枠のコマンドを貼り付けて Enter を押します。

1行ずつ貼り付けて Enter。終わって PS C:\...> がもう一度出てから、次の行に進みます。

  • 「このアプリがデバイスに変更を加えることを許可しますか？」には「はい」
全部終わったら、PowerShell と Claude Code をいったん両方閉じる

入れた道具を Windows に認識させるためです。開き直して、次の1行で確かめます。

「認識されません」と出たものがあれば、パソコンを再起動してから、もう一度確かめます。Git for Windows を入れておくと、Claude Code のコマンドが安定し、日本語の文字化けも起きにくくなります。

終わったら PowerShell を閉じて開き直し、もう一度 claude --version で確かめます。

TotonouMovie のフォルダを置く1分

  1. TotonouMovie-v2.2.0.zip を右クリック →「すべて展開」
  2. 中の「TotonouMovie」フォルダ（中に README.md と plugins があるもの）を、ユーザーフォルダ（C:\Users\あなたの名前）に移します。エクスプローラーのアドレス欄に %USERPROFILE% と入れて Enter を押すと、ユーザーフォルダが開きます
このフォルダは、消したり動かしたりしない

Claude Code はここから TotonouMovie を読み込みます。

プラグインを入れる1分

Claude Code の入力欄ではなく、ターミナルPowerShell に1行ずつ貼り付けます。

PowerShell

ターミナル・PowerShell

claude plugin list

totonou-movie@totonou と enabled が出る

開いていた Claude Code（デスクトップアプリかターミナル版）を一度閉じて、開き直します。

セットアップと動作テスト10〜20分

Claude Code を開きます（デスクトップアプリは Code タブでフォルダを選んで始める。ターミナル版は claude と入力）。はじめてのフォルダでは「信頼するか」を聞かれるので、自分のフォルダなら Yes。そして、こう話しかけます。

Claude Code に送る
TotonouMovie のセットアップをして

足りないものの確認 → 作業フォルダと名前の設定 → 文字起こしのモデルの準備（約3GB）→ 3秒のテスト書き出し、と順に案内してくれます。

聞かれること答え方
作業フォルダそのままで大丈夫です（ムービーの中の totonouC:\Users\あなたの名前\Videos\totonou）。Google ドライブ・OneDrive・iCloud・Dropbox の中は選びません
完成動画のコピー先（任意）完成した動画だけを Google ドライブなどに置きたいときに指定。なければ「なし」
名前カットの承認と完成の確認の記録に残ります
コマンドを実行してよいかuv run で始まる TotonouMovie の処理なら「Yes」。何度も聞かれるときは、内容を確かめて「Yes, and don't ask again」

最後のテスト書き出しで PASS

「同期フォルダの中です」→ Dropbox・iCloud などの外のフォルダで起動し直します。

2回目からの起動

ターミナル

totonoumovie

  • 終わるとき：起動したターミナル（PowerShell）で Ctrl＋C。編集は自動で保存されています
  • ブラウザを閉じてしまったら、ターミナルに出ている http://127.0.0.1:8780/ を開けば戻れます

うまくいかないとき

こんなときどうする
brew: command not foundHomebrew の導入の最後に出る「Next steps」の2行を実行し、ターミナルを開き直します
winget が見つからないMicrosoft Store で「アプリ インストーラー」を更新します
claude・uv・totonoumovie が見つからない入れたあと、ターミナル（PowerShell）を開き直していないことがあります。開き直して確かめます。Windows はパソコンの再起動も試します
/plugin isn't available in this environmentデスクトップアプリの Code タブで /plugin を送ったときの表示です。ターミナル（PowerShell）で「プラグインを入れる」の行を送ります
marketplace add でエラーTotonouMovie フォルダがホーム（ユーザー）フォルダの直下にあるか確かめます。中に README.md と plugins が見えるフォルダが正解です。claude plugin marketplace add （最後に空白）まで入力してから、フォルダをターミナルの窓にドラッグしても入れられます
急に「failed to load」と出るTotonouMovie フォルダを消したり動かしたりしていないか確かめます。元の場所に戻せば直ります
gh repo clone で「Could not resolve to a Repository」招待を受けていない、または別のアカウントでログインしています。招待メールの承認と、gh auth status のアカウント名を確かめます
動作テストが FAIL・「Timed out」回線が遅いと時間切れになります。遅い回線のときの手順で実行し直します
それ以外Claude Code に「TotonouMovie が動かない」と伝えると診断します。困ったときも見てください
