使い方

YouTube 動画を作る

横に撮った動画（16:9）を渡すと、YouTube 向けのロング動画の作り方になります。カットと字幕に加えて、長い動画では冒頭のハイライト、画面の章タイトル、概要欄に貼るチャプター、字幕ファイル（SRT）まで作ります。

5分を超える動画なら、章のタイトルとチャプターも作るよ。撮影中に「編集さん、ここに章」って言うと便利だよ。

頼み方

「🎬 AIで作る」で横の動画を選びます。3分を超える横の動画なら、自動でロングになります。3分以下のときは「ロングにするか、縦のショートにするか」を1回聞かれます（追加の指示に「YouTube 用」と書けば聞かれません）。

聞かずに決まること（既定）

項目既定
冒頭ハイライト5分を超える動画で、3つの型から候補を作り、③で選びます。5分以下は作りません
章タイトル・チャプター5分を超える動画で作ります
章カード撮影中に「編集さん、ここに章」と言った所に、2秒のカードを挟みます
字幕標準（横書き・画面の下）
効果音標準（8秒に1音ほど・ビジネス向け）
美肌弱め（40）。メインの出演者が女性なら60
画像画像フォルダを渡したか、「編集さん、ここに画像」と言ったときだけ
BGM曲を持ち込んだときだけ（控えめ）

4回の確認

確認内容
① 対談かどうか＋持ち込み話している人が2人以上なら、話者を分けて字幕に付けます。画像フォルダ・BGM・人名や用語の表記もここで伝えます
② カットの承認ロングの既定は「0.6秒以上の無音＋フィラー＋言い直し」。撮影中の合図の声と、話し始めの「はい」も候補に入ります
③ 仕上がりの確認本編を書き出す前に、30〜45秒の試作を音付きで作ります。字幕の見た目、口と声のずれ、章の切り替わりを確かめ、冒頭ハイライトの型（このまま／ほかの型／なし）も選びます
④ 完成の視聴完成した動画を見て OK と答えます

完成動画の構成

YouTube に上げるもの

ファイルYouTube のどこに
out/〇〇.mp4動画として上げます
output/youtube_chapters.txt中身を概要欄に貼ります。動画にチャプター（目次）が付きます
out/〇〇.srt字幕ファイルとして上げます（YouTube Studio の「字幕」）
チャプターの時刻は自動で合わせます

カット・冒頭ハイライト・オープニング・章カードをすべて計算に入れた完成動画の時刻で書き出します。YouTube の条件（最初が 0:00、3つ以上、それぞれ10秒以上）も満たすようにします。手で直す必要はありません。

SRT とチャプターは、AI に「仕上げて」「SRT とチャプターを作って」と頼むと作ります（totonoumovie の書き出しボタンは、完成動画まで）。

画像と BGM

  • 画像：縦長のスクショやグラフは人物の横に並べる「分割」、横長の画面は「収める」、写真は「全画面」でゆっくり寄ります。「収める」「全画面」の間は、左上の章タイトルを隠します
  • BGM：声より小さく流し、話している間はさらに下げ、章カードの間は止めます。権利を確認した曲だけを使います

くわしくは 合図と持ち込み素材。

対談の動画

①で「対談」と答えると、誰がいつ話しているかを判別して、字幕に話者を付けます（話者ごとに色を分けるなど）。このためのモデルは無料ですが、はじめて使うときに次の準備が要ります。

  1. Hugging Face のアカウントを作る
  2. 話者分離のモデルのページで、利用規約に同意する
  3. アクセストークンを作り、Claude Code が用意する .env ファイルに貼る

手順は Claude Code が案内します（「対談動画を編集したい」と伝えます）。トークンの値は、あなた自身がファイルに貼ります（チャットには書きません）。声紋を登録するのは、本人の同意を得た人だけです。話者が逆になっていたら「3分あたりから話者が逆」と AI に伝えると直します。

時間の目安と注意

10分の動画（画像3枚・BGM・章カードあり）で、機械の処理の合計は約24分です（Apple M5 Pro での実測）。書き出しはほかの重い処理と重なると30〜40分かかることがあるので、その間は別の作業をしていて大丈夫です。

  • 長い動画：30分なら、およそ3倍の時間を見込みます
  • 容量：10分の動画1本で、動画ごとのフォルダは約2.5GB。長いほど増えます
  • スリープ：パソコンがスリープすると処理が止まります。長い動画のときは電源につなぎ、スリープしない設定にします
