困ったとき

困ったとき・よくある質問

まずは下の欄に、画面に出た文字や困っていることを入れてみてください。当てはまる対処だけが残ります。それでも分からないときは、Claude Code に「TotonouMovie が動かない」と伝えると診断してくれます。

🔎 症状から探す

導入のとき

こんなときどうする
brew: command not foundHomebrew の導入の最後に出る「Next steps」の2行を実行し、ターミナルを開き直します
winget が見つからないMicrosoft Store で「アプリ インストーラー」を更新します
claude が見つからない（command not found・認識されません）Claude Code のターミナル版が入っていないか、入れたあとに開き直していません。開き直して claude --version で確かめます
uv・ffmpeg・gh・python が見つからないターミナル（PowerShell）を開き直します。Windows で直らなければパソコンを再起動します
/plugin isn't available in this environmentデスクトップアプリの Code タブでは /plugin が使えません。ターミナル（PowerShell）で claude plugin marketplace add から始まる行を送ります（入れかた）
marketplace add でエラーTotonouMovie フォルダがホーム（ユーザー）フォルダの直下にあるか確かめます。中に README.md と plugins フォルダが見えるフォルダが正解です
急に「failed to load」と出るTotonouMovie フォルダを消したり動かしたりしていないか確かめます。元の場所に戻せば直ります
gh repo clone で「Could not resolve to a Repository」招待を受けていない、または別のアカウントでログインしています。招待メールの承認と、gh auth status のアカウント名を確かめます
totonoumovie: command not found・認識されません入れかたの「どこからでも起動できるようにする」のあと、ターミナル（PowerShell）を開き直します。それでもだめなら、~/totonoumovie/totonoumovie$HOME\totonoumovie\totonoumovie.cmd で直接起動できます

totonoumovie の画面で

こんなときどうする
赤い帯「TotonouMovie プラグインが見つかりません」TotonouMovie の導入（プラグインを入れる）が済んでいません。入れかた A を済ませて、totonoumovie を起動し直します
黄色い帯「初期設定がまだのようです」Claude Code で「TotonouMovie のセットアップをして」と話しかけ、PASS まで進めます
赤い帯「同期フォルダの中です」Dropbox・iCloud・Google ドライブ・OneDrive の外のフォルダ（例：~/Movies/totonouVideos\totonou）に移動してから起動します
「claude コマンドが見つかりません」Claude Code のターミナル版を入れて、ターミナルを開き直します（claude --version で確認）
プロジェクトが一覧に出ないtotonoumovie は起動したフォルダの中を一覧します。プロジェクトのある作業フォルダで起動し直します
動画が再生されない・カクカクする右下に「軽い再生用の動画を準備中」と出ている間は少し待ちます。Google Chrome を使ってください
画面の字幕と完成の見た目が違う画面の重ね表示は近似です。正確な見た目は「📷 静止画」で確かめます
カットの承認で「候補または素材が変更されています」候補を作ったあとに素材や字幕の元が変わりました。「候補を作り直す」を押してから選び直します
カットを変えられない（フック適用済み）ショートで冒頭のつかみを入れたあとは、カットを変えられません。フックを入れる前の状態から作り直すかを AI に相談します
AI の作業が「⚠ エラー」になった「🤖 AI」から開いて内容を確かめます。返事を送れる状態なら「続けてください」と返すと再開できます
AI の作業が止まった・ターミナルを閉じてしまった作業は動画ごとのフォルダに残っています。totonoumovie を起動し直し、AI タブの「自由に頼む」で「続きをして」と頼みます
保存に失敗と出るほかのアプリでデータを開いていないか、空き容量があるかを確かめ、⌘S（Ctrl+S）で保存し直します

書き出しが「Timed out」で止まる（回線が遅いとき）

はじめて書き出すときは、書き出し用のブラウザ（約180MB）と字幕の字体を取得します。回線が遅いと、時間切れで止まることがあります。

  1. もう一度実行する：取得できた分は残るので、続きから進むことがあります
  2. 同時処理数を1にする：totonoumovie の書き出しで「同時処理数：1」を選びます
  3. AI に頼む：
Claude Code（または AI タブ）に送る
書き出しが Timed out で止まる。並列数を1にして、待ち時間を900秒にしてやり直して

毎回そうなるときは「書き出しの並列数をいつも1にしたい」と伝えると、設定のしかたを案内します。

Claude Code そのもののこと

こんなときどうする
Claude Code が開かない・サインインできないTotonouMovie ではなく Claude Code 側のことです。有料プランのアカウントでサインインしているかを確かめます
「You've hit your … limit · resets …」と出て止まるClaude の利用の上限に達した表示です。表示された時刻を過ぎると、また使えます。時刻を過ぎたら「続きをして」と頼みます
動画のファイルが見つからないと言われるパスが違っています。totonoumovie なら「選ぶ」ボタンで選び直します。Claude Code なら動画を入力欄にドラッグします

編集・書き出しのとき

こんなときどうする
書き出しが途中で止まる・遅い作業フォルダがクラウド同期の中にないか確かめます。ほかの重い作業と重なると、数倍遅くなることもあります
字幕の字体がいつもと違う書き出しのときに字体をインターネットから取得します。接続を確かめます。オフラインだと標準の字体に置き換わります
はじめての文字起こしが遅い最初の1回は、約3GBの文字起こしモデルを取得します。2回目からは速くなります
字幕が声より早い・遅い編集画面で字幕をドラッグして合わせるか、「1分10秒あたりの字幕が声より早い」と AI に伝えます
合図が効かなかった前後に間を空けて、単独で言ったかを確かめます。文の途中だと合図と判定されにくくなります。言い方を変えた場合は、設定の言い方で言います
容量が足りない空き容量は20GB以上を目安に。仕上がった古い動画のフォルダを外付けのドライブなどに移すと空きが増えます（あとで直すときは元の場所に戻します）
検査で WARN（注意・🟡）が出たWARN は不合格ではありません。理由が出るので、気になる所だけ確かめます。FAIL（⚠）のときは直して書き出し直します

よくある質問

音声や動画を外部に送りますか？
音声や動画のファイルは送りません。文字起こしはパソコンの中で動きます。ただし、文字起こしの文章や、確認のために作る画像（動画のコマ）は Claude が読むので、Claude Code のふだんの会話と同じように Anthropic に送られます。ほかに、書き出しのときに字幕の字体をインターネットから取得します。
インターネットは必要ですか？
必要です。Claude Code は、使っている間ずっとインターネットにつながっている必要があります。導入のときのダウンロードと、書き出しのとき（字体の取得）にも使います。
会社で使えますか？
会員ご本人が、仕事の動画づくりに使えます（ほかの社員との共有はできません）。ただし、書き出しに使っている Remotion は、社員4人以上の会社では有料の会社ライセンスが必要です。個人と3人以下の組織は無料です。
1本作るのにどれくらいかかりますか？
機械の処理だけで、35秒のショートなら約5分、10分のロングなら約24分が目安です（Apple M5 Pro での実測）。これに確認に答える時間が加わります。
途中でやめても大丈夫ですか？
大丈夫です。作業は動画ごとのフォルダに残ります。totonoumovie で開き直して、AI タブの「自由に頼む」で「続きをして」と頼めます。Claude Code の同じ会話の中なら「続きをして」で続きます。
totonoumovie と Claude Code（チャット）、どちらで作ってもいいですか？
どちらでも同じ TotonouMovie が動き、同じフォルダにプロジェクトができます。チャットで作った動画を totonoumovie で開いて直すことも、その逆もできます。
同じ動画からショートとロングの両方を作れますか？
作れます。横の動画を YouTube 用に仕上げたあと、同じ元の動画から「この横の動画を縦にしてからリールにして」と頼むと、ショートを別に作ります。横の完成動画をそのまま縦にした版も書き出せますが、字幕が横の幅のまま入るので、縦では端が見切れることがあります。
完成した動画は誰が最終確認しますか？
あなたです。機械の検査は抜けやずれを見つけますが、言葉の正しさまでは保証しません。④の視聴で最後まで見て確かめます。

質問するときに伝えること

自分で解決できないときは、TotonouMovie（totonoumovie）を受け取った窓口に質問します。次の5つを添えると、早く答えが見つかります。

  1. パソコン（Mac か Windows か）と、使っている画面（totonoumovie／デスクトップアプリ／ターミナル版）
  2. 何をしようとしたか（例「リールを作ろうとした」）
  3. 出たメッセージ（画面の文字をそのまま。totonoumovie なら右下の「ログ」の中身）
  4. どこまで進んだか（例「②のカットの承認のあと」）
  5. Claude Code に「TotonouMovie が動かない」と伝えたときの診断の結果
