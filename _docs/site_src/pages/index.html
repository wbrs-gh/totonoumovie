作れる動画は3種類

動画の向きを見て、作り方は自動で決まります。迷ったら「この動画を編集して」と渡すだけで大丈夫です。

縦の動画

リール・ショート

Instagram リール・YouTube Shorts・TikTok 向け。字幕の雰囲気を選べて、冒頭のつかみや最後の案内も入れられます。
横の動画

YouTube 動画

長い動画のカット、章のタイトル、概要欄のチャプター、字幕ファイル（SRT）まで作ります。
声＋素材

アフレコ動画

声の録音と、風景や手元の動画・写真から、字幕と映像が同時に切り替わる縦動画を作ります。

こう変わります（実際に作ったサンプル）

同じ撮影素材を TotonouMovie で仕上げた例です。左が撮ったまま、右が完成です。無音と「えーっと」が切られ、字幕・強調・効果音・画像・寄りが入っています。

※ 説明のためのサンプルです。人物の写真は AI で作り、声は合成音声（VOICEVOX:もち子さん）です。

どう動くの？

totonoumovie は、あなたのパソコンに入っている Claude Code と TotonouMovie を、ブラウザの画面から動かすアプリです。動画はパソコンの中で処理され、編集の内容もパソコンの中に保存されます。

決めるのは、いつもあなた

AI はカットの候補を出すだけで、切るかどうかはあなたが選びます。完成の確認も、あなたが最後まで見て OK を出します。

TotonouMovie がしてくれること

作業内容
✂️ カット無音・「えー」「あのー」・言い直しの候補を AI が出し、あなたが選んだものだけ切ります。勝手には削りません
💬 字幕文節の区切りで読みやすく出します。明るい背景でも読めるよう、縁取りを自動で強めます
✨ 演出効果音、つなぎ目を目立たなくする寄りの切り替え、強調の動きを入れます
🔊 音声雑音を減らし、YouTube の標準の音量（-14 LUFS）にそろえます
🖼 持ち込み素材画像・写真・スクショを話の内容に合わせて差し込み、持ち込んだ曲を BGM として控えめに流します
🎙 撮影中の合図撮りながら「編集さん、ここに章」などと言うと、その場所に章のカードや画像が入ります
🔍 検査書き出した動画を自動で検査し、完成した音を文字起こしし直して、字幕の抜けや遅れを確かめます
🎨 マイスタイル気に入った見た目を名前を付けて保存し、次の動画で「前回と同じで」と呼び出せます

くわしくは 機能の一覧 を見てください。

はじめに知っておいてほしいこと

作業フォルダは、クラウド同期の外に

Dropbox・Google ドライブ・OneDrive・iCloud の中で編集すると、書き出し中に同期とぶつかって止まることがあります。作業はパソコンの中のフォルダ（例：ムービーの中の totonou）で行い、完成した動画だけをコピーします。

音声ファイルは外に送りません

文字起こしはパソコンの中で動きます。文字起こしの文章や確認用の画像は、Claude Code のふだんの会話と同じように Claude が読みます。書き出しのときは字幕の字体（Google Fonts）をインターネットから取得するので、接続は必要です。
