使い方

撮影中の合図と持ち込み素材

撮影しながら「ここに章」「ここに画像」と言うだけで、その場所に編集が入ります。画像・BGM・人名や用語の表記も、最初の確認で一緒に渡せます。

撮影中の合図

言うこと入る編集使える動画
「編集さん、ここに章」ここから新しい章。2秒の章カードが入り、左上の章タイトルが切り替わります。YouTube のチャプターの区切りにもなりますロング
「編集さん、ここに画像」直前に話した内容に合う画像を、持ち込みの画像から差し込みますロング・ショート
「編集さん、ここに一覧」このあとに話す項目を、話した順に1行ずつ増える一覧の字幕にしますロング
  • 前後に少し間を空けて、はっきり言います。文の途中で言うと、合図と判定されにくくなります
  • 「編集さんに後で確認してもらいます」のような普通の会話や、合図の使い方の説明では作動しません。合図かどうか迷ったものは、あなたに聞かれます
  • 「ここに一覧」のあとは、「一つ目は〇〇。二つ目は〇〇。」のように区切って話すと、きれいに並びます
  • 合図の声はカット候補になり、あなたの承認で切られます。アフレコ動画では合図は使いません
言い方は変えられます

Claude Code に「合図の言い方を『カメラさん、ここに章』に変えたい」と伝えると、設定を変えてくれます（設定を変える）。

画像・写真・スクショ

画像を1つのフォルダにまとめて渡すと、話している内容に合わせて差し込みます。totonoumovie の編集画面で、あとから足す・外す・動かすこともできます。

  • 形式は jpg・png。iPhone の HEIC は、写真アプリなどで JPEG に書き出してから入れます
  • 1枚4秒以上、画像と画像の間は1秒以上。冒頭と最後の余韻には置きません
  • 画像が足りないときは、画像を作るための依頼文（生成 AI に渡す文）を書いて渡します。TotonouMovie は画像を生成しません

3つのレイアウト

位置と割り当ては③の仕上がりの確認で見せるので、「この画像は外す」「別の文へ」「レイアウトを変える」と伝えて直せます。縦動画では分割は使わず、「収める」か「全画面」になります（1枚6秒以内・最大3枚が目安）。

BGM

  • 使えるのは、あなたが使ってよい権利を確認した曲だけです。確認したかを聞かれます（totonoumovie では BGM の設定の「権利を確認済み」にチェック）。TotonouMovie は曲を選んだり作ったりはしません
  • 音量は「控えめ」（既定）と「標準」の2段です。控えめは、話している間はほとんど聞こえず、間や章の切り替わりで聞こえる程度です
  • 曲が動画より短いときは繰り返します。元の動画にすでに音楽が入っている素材では、曲が重なって聞こえるので、確認のときに伝えてください

人名・用語の表記

人名・社名・商品名・専門用語の正しい表記を、最初に1回だけ伝えます。文字起こし・誤字の修正・字幕・検査の4か所で使われるので、同じ間違いを何度も直さずに済みます。

「今回だけの追加の指示」に書く例
表記は「山田太郎」「ととのう」「整え方メソッド」

2本以上の動画で同じ直しが出たら、共通の辞書に足すかを提案されます（自動では足しません）。

まとめて渡す書き方

「今回だけの追加の指示」
画像は /Users/あなたの名前/Pictures/talk-images に入っています。BGM は /Users/あなたの名前/Music/calm.mp3（権利確認済み）。表記は「山田太郎」「ととのう」。
「今回だけの追加の指示」
画像は C:\Users\あなたの名前\Pictures\talk-images に入っています。BGM は C:\Users\あなたの名前\Music\calm.mp3（権利確認済み）。表記は「山田太郎」「ととのう」。

最初から書かなくても、①の確認で「画像フォルダ・BGM の曲・人名や用語の表記があれば」と聞かれるので、そのときに答えても同じです。

権利と出所の記録

持ち込んだ画像と曲の権利は、あなたが確認します。TotonouMovie は、どのファイルをどこで使ったかの記録（work/assets_log.json）を残します。
